# Léeme primero

Esto es lo único que haces a mano. Todo lo demás lo hace Claude Code siguiendo `CLAUDE.md`.

## 1. Instala VS Code

Descárgalo de https://code.visualstudio.com e instálalo (versión 1.94 o más reciente).

## 2. Instala la extensión de Claude Code

1. Abre VS Code.
2. Presiona `Ctrl+Shift+X` (Windows/Linux) o `Cmd+Shift+X` (Mac) para abrir Extensiones.
3. Busca **Claude Code** (de Anthropic) y dale **Install**.
4. Abre el panel de Claude con el ícono de chispa en la barra lateral izquierda.
5. Dale **Sign in** y autoriza en el navegador con tu cuenta de Claude (necesitas un plan de pago: Pro, Max, Team o Enterprise).

## 3. Abre esta carpeta

1. Descomprime esta carpeta donde quieras guardar el proyecto (por ejemplo en Documentos).
2. En VS Code: **Archivo → Abrir carpeta** y elige `albion-command-os`.
3. Revisa que estén `CLAUDE.md`, `LEEME.md` y `docs/PLAN.md`.

## 4. Arranca

En el panel de Claude Code escribe:

> Lee CLAUDE.md y docs/PLAN.md y empieza con la primera sesión de arranque.

Claude te va a ir guiando: revisa qué programas faltan y te pide permiso para instalarlos, te pide que crees tus cuentas de GitHub y Cloudflare, crea el repositorio y empieza la Fase 0. Cuando te pida iniciar sesión en GitHub o Cloudflare, lo haces tú en el navegador; nunca le pegues contraseñas en el chat.

Más información sobre la extensión: https://code.claude.com/docs/en/vs-code
